If this is useful to you, consider supporting us on Patreon.

StatusAPI Terms of ServiceView API Documentation
We host a public API (https://api.polyhaven.com) that can be used to access and download our assets, with a few conditions.
What can I do with the API?
We encourage you to use the API to integrate our assets into your tool/software, or to bulk-download the dataset for research purposes.
Example use cases we know about:
Third-party asset browsers and game engine importers that let people drag-and-drop our assets in-app.
Bulk-downloading for academic research or training data for AI/ML pipelines that need clean, human-made, CC0-licensed resources.
Internal asset-management tools and pipelines at studios that depend on the library day-to-day in production.
Our own Blender Add-on, which pulls assets directly into your scene without visiting the website.
You should read the full Terms of Service of the API, but in summary:
1. ✅ The API is free to use, for any purpose
Personal, academic, or commercial. There's no premium tier, no revenue share, and no login or API key required for the default endpoints.
It is a public API for the public benefit. Consider supporting us on Patreon if you find it useful!
2. ⚠️ Attribution required
If you use the live API in your product, website, or service, make it clear to your users that the assets came from Poly Haven.
Any clear credit works for this - labelling it in your interface (a title, menu item, or button that names Poly Haven) is great, and so is a small "Powered by Poly Haven" credit near the content if that fits your product better. Feel free to use our logo if it helps.
This is a condition of using the live API service, not of the assets themselves: the assets are CC0.
3. ⚠️ Unique User-Agent required
All requests to the API require a unique User-Agent header, such as your application name, so that we may track your usage.
For example:
curl -H "User-Agent: MyAssetBrowser/1.0" https://api.polyhaven.com/assetsBest effort
We primarily maintain the API for our own purposes and may occasionally change endpoints and authentication methods. If you are integrating our API in your tool on the user side, please contact us so that we are aware of it and can notify you of any relevant changes.
We also love hearing about how you are using the API ❤️
If your company depends heavily on the API in production, you're welcome to help fund the operational side of things - such as a signed Provenance Attestation or a Bulk Snapshot - via our corporate page. This is entirely optional and never required to use the API.
See our status page for uptime stats: https://status.polyhaven.org
What's in it?
Check the full documentation for a list of endpoints and examples. In a nutshell, the API includes:
A list of all assets.
Information and metadata about each asset, such as tags and categories, authors, dimensions, etc.
Download URLs, hashes and file sizes of all asset files.
For files with dependencies (e.g. Blend/USD needs the image texture files), a list of the required files and their URLs.
In short, the API includes everything you need to browse and download our assets.
