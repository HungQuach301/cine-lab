Creation methods¶
The 3D assets on ambientCG were created using a variety of methods. You can select them using the dropdown on the /list page.
Method
Description
Example
Approximated
The material has been approximated from just a color map.
Photogrammetry
The material’s displacement map was created using photogrammetry.
Procedural
The material was created fully procedurally - usually in Adobe Substance 3D Designer.
Multi Angle Lighting
The material was created using multi-angle approximation. By shining light on a surface from different angles it is possible to create a height profile. This is usually done for leaves.
Plain Photo
Just a plain photo, no further material processing was done. This is usually used for backdrops.
Stitched HDRI
An HDRI environment that was stitched from numerous photos.
Stitched HDRI (Edited)
An HDRI environment that was stitched from numerous photos with additional heavy processing, like "cleaning" the horizon and removing the bottom half.
3D Photogrammetry
This asset is a 3D model that was created using photogrammetry.
